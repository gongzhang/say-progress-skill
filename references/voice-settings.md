# 调整系统语音

引导用户打开「系统设置 → 辅助功能 → 阅读与朗读」：

1. 将「系统语音语言」设为播报文本对应的语言；中文普通话选择「中文（中国大陆）」。
2. 点按「系统声音」旁的 ⓘ，进入对应语言，下载并试听名称含 `Siri` 的声音，例如 `Siri Voice 1` 或 `Siri Voice 2`。名称可能随系统语言和版本变化。
3. 等待下载完成，返回并点按「完成」，再从「系统声音」中选中刚下载的 Siri 声音。
4. 运行 `/usr/bin/say "你好，这是新的系统语音。"` 试听；保持命令不带 `-v`，使其沿用系统默认声音。

下载未完成的声音不可用。若列表中没有 Siri 声音，选择同语言下听感最自然的增强声音。

参考：[Apple《更改 Mac 用来朗读文本的声音》](https://support.apple.com/zh-cn/guide/mac-help/mchlp2290/mac)
